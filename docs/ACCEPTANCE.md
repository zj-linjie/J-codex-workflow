## 浏览器验证

环境：Codex 内置浏览器；开发样例 `http://127.0.0.1:57337/`；实际视口719×857、窄屏390×780。开发宿主显式标明“非 Codex 宿主”，零用户数据。

实际操作：草案 → 执行中 → 待验收 → 展开能力核查详情 → 暂停 → 模拟断连 → 恢复连接 → 完成。用 AX/DOM 状态和浏览器截图核对：

- 页面身份正确、内容非空，无框架错误覆盖层；阶段轨道在窄屏横向滚动，标题与状态可读。
- 角色职责、验收标准、原生 ID、摘要、产物引用可展开；revision更新后保留展开状态。
- 断连保留最近数据并提示重试；恢复且 revision 不变时也能清除旧错误提示。
- 完成后显示“自动同步已停止”；读取计数在3.5秒观察内保持179，终态DOM回执为同一run、全done、visible。
- 修复了 loading hidden 被 CSS 覆盖、恢复后错误 banner 残留和详情折叠三项浏览器问题。

控制台留有一条最初加载时的 MutationObserver 报错；项目页面和开发宿主源码均没有使用 MutationObserver，未复现为本应用行为故障。当前交互与渲染检查通过，但不宣称整个宿主控制台零错误。截图在本次会话工具输出中，未保存独立截图文件。

未验证：正式插件宿主里的主题切换、断连/重启恢复、多张原生卡片并行、实际暂停/取消与子代理控制。不能用开发宿主结果替代这些验证。
